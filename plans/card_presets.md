# Card presets to build

Slots: top row 1 to 4, bottom row 5 to 8. "(doubled)" = that slot is doubled by your lab chip, so the big card goes there.
"leave empty" = nothing that isn't passive helps there.
Preset numbers mean the same thing on everyone. Card sets aren't here; the card will tell you the set when it tells you to switch.

## Cheap card set upgrades (do when you can)

1. Bosses n Nightmares: get 1 Verminous card. Set goes from 24% to 30% Damage, Drop and EXP, used by presets 1, 3, 4, 6 on everyone. Pulse: farm it on the Insta castle map with Wind Walker + candy (mixed reports, test it).
2. Events: 8 card stars to go from 7% to 14% Drop Rate. Easiest: 1 more Chocco Box, first Giant Rose, first Shell Snake.
3. Smolderin' Plateau: first Crystal Glunko card gets 1 of the 4 stars needed for 10% Fight AFK (now 8%).
4. Shimmerfin Deep (W7): 9 card stars for 10% Class EXP Multi (now 0). Coralcave Guardian counts here and is also a missing drop rate multi card.
