# Brother's dashboard (IdleOnLech, 10 characters)

Separate from Zack's account. Runs on GitHub + Cloudflare free tiers, no Claude usage.

## How it updates
1. He cloud saves in game.
2. Toolbox (signed in) > Account menu (top right) > Copy raw data.
3. Pastes it at `https://idleon-brother.pages.dev/upload.html` with the passcode.
4. The page commits `inbox/raw.json.gz` -> `.github/workflows/brother.yml` runs `run.sh` (copy of Zack's pipeline, brother data) -> commits `snapshots/ plans/ dashboard/` here -> deploys to Cloudflare Pages. About 3 minutes.

Why paste and not auto-pull: Toolbox's public profile server only answers its own site (403 elsewhere); we don't fake that.

## Files
- `jobs.yaml`: AUTO-GENERATED by `make_jobs.py` from Zack's `model/jobs.yaml` (same jobs by class role). Change owners in `make_jobs.py` ROLE/MOVE and rerun.
- `run.sh`: builds in a throwaway copy, never writes Zack's files. `patch_copy.py`: swaps Zack-only text in that copy.
- Browser-only parts of Zack's setup (Toolbox dashboard timers, Sailing/Farming/Cooking page reads) are not available here; those planners skip.

## One-time setup (Zack)
GitHub repo > Settings > Secrets and variables > Actions > New repository secret, add:
- `CLOUDFLARE_ACCOUNT_ID`: Cloudflare dashboard > Workers & Pages > Account ID (right side).
- `CLOUDFLARE_API_TOKEN`: Cloudflare > My Profile > API Tokens > Create Token > Custom: Account / Cloudflare Pages / Edit.
- `UPLOAD_GH_TOKEN`: GitHub > Settings > Developer settings > Fine-grained tokens > only this repo, Repository permissions > Contents: Read and write.
- `UPLOAD_PASSCODE`: any passcode you pick; give it to your brother.
Then Actions tab > brother-dashboard > Run workflow (first deploy).
