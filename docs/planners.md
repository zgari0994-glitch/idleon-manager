## Per-system goal standard (Zack 2026-11-27, approved; replaces the Plan: Now/Next/Stop/Waiting section)
Auto-drafts (2026-11-28): `python3 tools/draft_goals.py [system]` writes a DRAFT block (status: DRAFT, auto: true) from lookup (creator priority/target/how_to/blocker claims first, then AutoReview); non-sourced ones are logged in brain/goal_gaps.md. Drafts are never approved until Zack says so. Trigger rows live in brain/triggers.yaml (evaluated per owner card by model/syscheck2.py).
Every file in brain/systems/ gets one GOAL block (template: brain/systems/_TEMPLATE_goal.md). Mapping of the old fields: Now + Next -> objective + ladder; Stop point + Waiting on -> stall + triggers. Human notes stay below the block.
1. role: blocker / feeder / independent vs the main goal. Blocker -> Law 1 (owner hard-focuses, every task aims at the unblock).
2. goal: end state + why.
3. ladder: measurable rungs from creator guidance, each with source + date. No creator coverage -> "my read" rungs from the data + log the gap.
4. objective: next rung, now vs target, ETA from model/rates.py.
5. check: daily or weekly, who, what to look at -> card Do line (Law 2).
6. buffs: sources across W1-W7, owned/missing, owner + next level. Only for systems that are behind or need a push (split from model/buffs.md); timed self-running systems get one line.
7. triggers: when X hits Y -> do Z (rung done, unlock, reserve freed, feed next system).
8. stall: no progress in 3 pulls OR ETA over 30 days, whichever first. Card + report flag with reason; reason = another system -> Law 1 routes it.
9. tasks: each with score inputs, ranked by docs/scoring.md.
Plus coverage grade (sourced / partial / my read / none), used by the audit.

Rollout: (1) standard [done 2026-11-27] -> (2) audit all brain/systems vs standard: has plan / partial / nothing, ranked backlog, plus which can't emit scored tasks yet -> (3) system by system (divinity, gaming, cooking stuck at 111, anvil + armor, vials vs trapping, Salt Lick, Bubba, stamps, cards to 6-star, golden food first), creator guidance pulled, plan approved, then into the pipeline. model/score.py build = its own approved step.

## Phase C A+B: live now, real stall, machine triggers, goal challenge (Zack 2026-11-28)
- `now_path:` (top level of the GOAL yaml, optional `now_op: "<="` for spend-down targets) is resolved by model/livepath.py every pull.
  Spec: `a.b[*].c|reducer` on the parsed account, `@Autiszemo.path` on a character, `metric:name` (syscheck2.metrics), or a number.
  Tokens: key, `*`, `[N]`, `[*]`, `[k=v]`, `[k~v]` (contains), `[k>N]`, `[k<N]`. Reducers: min max sum len count first.
- No now_path -> `now: not in save (last written: ...)`. Path set but missing -> `not in save (path ...)`. Never None, never a guess.
- Stall fingerprint = hash of the live now only, history in state/goal_now_history.json (old goal_history.json retired: whole-blob hashes moved with timers). Data stall needs N fresh pulls to arm.
- TARGET HIT (live): when now meets target (op, default >=) the rung is done and the next open rung becomes the target on the card; last rung = confirm maintained. Zack updates the md ladder when convenient.
- Triggers (brain/triggers.yaml rows and GOAL block `triggers:`): `when_path`, `op` (>= <= > < == != truthy), `value` (number, path or metric:name), optional `target:` system. Fired -> "DO NOW: then" (GOAL: flag on the goal line); armed -> "next: when (now / value)"; when_path null -> check in game.
- Goal challenge: objectives recompute each pull. Zack's plans (brain/plans.yaml) are never removed by the model; they show "challenge?" when a plan carries `challenge: {why, source}` (a sourced order found in research) or one of his scored tasks beats the plan's task by challenge_margin (15). Plans with no `task:` only get the sourced flag.
- Tie-break: equal scores sort by impact x reach (`tie`), no effort floor.
